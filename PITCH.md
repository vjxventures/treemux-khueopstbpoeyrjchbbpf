# Sentinel: AI-Native Incident Response

**What if PagerDuty were founded in 2026?** Instead of just paging humans about outages, Sentinel deploys autonomous AI agents that investigate incidents in real-time — analyzing logs, querying metrics, correlating with past outages, and executing remediation — all while streaming their reasoning to a collaborative dashboard where engineers can interact and guide the process.

Sentinel reimagines PagerDuty (YC W10) as an AI-native platform where the first responder to every production incident is a Claude-powered agent with six specialized tools (log analysis, service health checks, metrics queries, deployment history, incident correlation, and remediation execution). The agent autonomously identifies root causes like connection pool exhaustion or memory leaks by cross-referencing real-time data across multiple services, then proposes and executes fixes — cutting mean time to resolution from hours to seconds.

Built with Next.js, the Vercel AI SDK, and Claude's multi-step tool-calling capabilities, Sentinel demonstrates how AI agents can transform operations teams from reactive firefighting to proactive, automated incident management — a $4B+ market ripe for disruption.
